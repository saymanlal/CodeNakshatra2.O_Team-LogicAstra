Getting Started

Start building on SAYMAN in minutes with our comprehensive guides and SDKs.

Install SDK

npm install @sayman/sdk

Create a Wallet

const { Wallet } = require('@sayman/sdk');
const wallet = new Wallet();
const address = wallet.generateAddress();
console.log('Address:', address);
💡 Tip: Always back up your private key securely. Never share it with anyone.
